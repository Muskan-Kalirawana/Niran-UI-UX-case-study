# NIRAN – AI-Powered Study & Accountability Companion

**Tagline:** Small Promises. Big Futures.

## About the Project
NIRAN is an AI-powered student productivity application designed to help students overcome procrastination, manage daily tasks and build consistent study habits.

## Key Features
- AI Companion
- Personalized Study Planning
- Smart Task Management
- Habit Tracking
- Focus Sessions
- Reminders and Notifications

## UX Design Process
- User Research
- User Personas and Empathy Mapping
- User Journey Mapping
- Information Architecture
- Wireframing
- UI Design and Prototyping
- Usability Testing

## Tools Used
Figma, UI/UX Design, Prototyping
